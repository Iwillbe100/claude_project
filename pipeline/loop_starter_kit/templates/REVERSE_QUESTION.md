# 되물음 양식 (Reverse Question)

루프가 **혼자 판단하지 않고 나에게 묻는** 형식입니다.
`evidence/runs/<run_id>/reverse_question.md`로 저장하고, 내 답은 `PROJECT_MEMORY.md` 7번에 남깁니다.

---

## 언제 뜨나

| 때 | 왜 |
| --- | --- |
| 루프 A(정보량)가 끝났을 때 | 이만큼 모았는데 계속할지 물어본다 |
| 루프 B(페이지)가 끝났을 때 | 화면이 다 찼으니 정성 점검으로 넘어가라고 |
| 루프 C(정성 3회)가 끝났을 때 | 눈으로 한 번 보고 마치라고 |
| 상한에 걸렸을 때 | 더 돌지, 넘어갈지, 멈출지 |

---

## 양식 — 루프 A · B 가 끝났을 때 (못 채운 칸이 남았느냐로 둘 중 하나)

**통과했을 때** — 판정기 exit 0 · 못 채운 칸 0. `D-사람확인지점` 이 루프 끝마다 묻게 되어 있으면 통과해도 이 되물음을 띄운다.

```text
[되물음] (어느 루프)가 끝났습니다. 못 채운 칸 없이 통과했습니다.

  채운 것    : M / M 칸 (판정기 exit 0)
  못 채운 것 : 없음

  지금까지 : (반복 횟수)바퀴 · 같은 오류 (횟수)회
  기계가 못 본 것 : (있으면 한 줄씩 — 예: 사진이 그 장소가 맞는지. 없으면 이 줄을 지운다)

  고르세요
   [1] 더 손본다                      → 판정기로는 할 일이 없습니다. 고칠 곳을 적어 주면 그 칸만 고칩니다
   [2] 다음 루프 (루프 B / 루프 C)로 넘어간다    ← 권장
   [3] 여기서 멈춘다                  → 지금까지 만든 것은 그대로 남습니다 (뒤 루프를 안 돌았으므로 SUCCESS 는 아닙니다)
```

**부족이 남았을 때** — 상한에 걸렸거나, 되물음 지점에서 아직 SHORT(exit 2)다.

```text
[되물음] (어느 루프)가 (끝났습니다 / 상한에 걸렸습니다).

  채운 것    : N / M 칸
  못 채운 것 :
    - (칸 이름) — (왜 못 채웠는지 한 줄)
    - (칸 이름) — (왜 못 채웠는지 한 줄)

  지금까지 : (반복 횟수)바퀴 · 같은 오류 (횟수)회

  고르세요
   [1] 부족한 칸만 다시 모은다        → 예상 (분)분, 성공 가능성 (높음/낮음)
   [2] 부족한 채로 다음으로 넘어간다   → 못 채운 칸은 보고서에 그대로 남습니다 (최종 상태는 SUCCESS 가 아니라 HALT_*)
   [3] 여기서 멈춘다                  → 지금까지 만든 것은 그대로 남습니다
```

> `HALT_*` 안내는 **부족이 남았을 때만** 붙인다. 못 채운 칸 없이 통과한 루프에 붙이면
> `SUCCESS` 로 끝날 실행을 실패처럼 읽게 된다.

---

## 반드시 지키는 것

1. **선택지를 준다.** "도와주세요"라고만 쓰지 않는다.
2. **각 선택의 결과를 적는다.** 시간이 얼마나 더 드는지, 무엇이 남는지.
3. **못 채운 것을 숨기지 않는다.** 조용히 넘어가는 것이 가장 나쁜 실패다.
4. **권장안을 하나 고른다.** 다만 정하는 사람은 사람이다.

---

## 루프 C에서는 되물음이 다르다

루프 C는 상한이 아니라 **정해진 3회**입니다. 그래서 중간에 "더 돌까요"를 묻지 않습니다.

```text
1·2회차가 끝났을 때   묻지 않는다. 남은 회차를 그대로 돈다
3회차가 끝났을 때     묻는다 — 무엇을 고쳤는지 보여 주고 브라우저 확인을 청한다
되돌아감이 생겼을 때   묻는다 — 정성 수정이 정량 계약을 깨뜨렸다
```

```text
[되물음] 정성 점검 3회를 마쳤습니다.
  1회차 : 취향 설명 복제 21줄 교체 · 상세 3요소 보강 4곳
  2회차 : 일정 시간 재배치 2곳 · 근거 없는 문장 3개 삭제
  3회차 : 고칠 것 없음 (파일 그대로)
  남은 것 : 사진이 그 관광지가 맞는지는 기계가 볼 수 없습니다

  고르세요
   [1] 브라우저로 확인했다. 마친다        ← 권장
   [2] 고칠 곳을 적어 준다               → 고친 뒤 정성 3회를 처음부터 다시 돕니다
                                           (4회차는 없습니다. 판정기는 3회만 봅니다)
   [3] 여기서 멈춘다
```

## 권장안을 고르는 기준

```text
못 채운 칸 없이 통과했다             →  [2] 다음 루프로 넘어가기를 권한다 ('통과했을 때' 양식)
같은 오류가 2번 이상 반복됐다        →  [2] 넘어가기를 권한다
아직 한 번도 다시 시도하지 않았다     →  [1] 다시 모으기를 권한다
파일이 깨졌거나 권한이 없다           →  [3] 멈추기를 권한다
```

> 인터넷에 없는 정보는 몇 바퀴를 더 돌아도 없습니다.
> 그럴 때는 **넘어가고 보고서에 적는 편**이 시간을 아낍니다.
