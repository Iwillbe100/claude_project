# 내 여행 요청서

**여기가 루프의 출발점입니다.** STEP 1에서 이 파일을 채웁니다.

세 가지는 **반드시** 있어야 루프가 시작됩니다.

```text
1  국가          어느 나라
2  여행 일수     며칠
3  여행 스타일   무엇이 좋고 무엇이 싫은가
```

---

## 1. 국가와 일수

| 항목 | 값 |
| --- | --- |
| 국가 | 일본 (오사카·고베) |
| 여행 일수 | 4일 (11/13~16, 3박4일) |

## 2. 여행 스타일 — 편하게 말하듯 쓰세요

**격식 차리지 마세요.** 평소에 친구한테 말하듯 쓰는 게 제일 좋습니다.
AI가 이 말투에서 취향을 읽어 도시와 관광지를 고릅니다.

### Preferred — 좋아하는 것

```text
맛집
휴식, 쇼핑
```

### Not preferred — 싫어하는 것

```text
여행일정에서 많이 걸어야하는건 싫어
```

### Detailed preference — 세부 사정

```text
오사카-고베를 갈꺼야. 고베마라톤에 참가하면서 겸사겸사 가는거야.
11/15일 대회야. 대회를 뛰어야해서 여행일정에서 많이 걸어야하는건 싫어
여행 일정은 11/13~16(3박4일)
```
