# =============================================================================
# requirements.lock.txt  --  LangGraph 실습 환경의 단일 설치 파일
# -----------------------------------------------------------------------------
#   기준 인터프리터 : CPython 3.12.x  (다른 버전도 설치는 되지만 검증되지 않았다 -> verify_env C01 이 FAIL)
#   설치            : python -m pip install --require-virtualenv -r settings/requirements.lock.txt
#   검증            : python settings/scripts/verify_env.py
#   (둘 다 킷 폴더에서, 프로젝트 .venv 의 python 으로. SETUP.md "빠른 시작" 참고)
#
# 플랫폼 차이: macOS/Linux 에서는 langgraph-api 가 uvloop · httptools 를 더 요구해 81개가 된다
# (Windows 에서 계산한 lock 이라 이 둘은 고정돼 있지 않다). Intel Mac 은 cryptography==50.0.1
# wheel 이 없어 소스 빌드로 떨어진다 -> SETUP.md 부록 B.
#
# 이 파일을 수정하지 말 것. 버전을 바꾸면 강사 환경과 달라진다.
# extras 표기([inmem] 등)를 쓰지 않으므로, pip 의 -c 제약 파일로도 그대로 재사용할 수 있다.
#
# -----------------------------------------------------------------------------
# 왜 79개나 되는가 (직접 세어 확인한 수치)
# -----------------------------------------------------------------------------
# 아래 4계층은 "직접 의존성 9종에서 출발한 의존성 폐포"를 실제로 계산해 나눈 것이다.
# 군더더기는 0건이다. 즉 어느 한 줄을 지워도 설치 결과가 줄지 않는다.
# pip 이 어차피 의존성으로 다시 끌어오되, 이번에는 **버전이 고정되지 않은 채로**
# 들어온다. 지우면 환경이 가벼워지는 게 아니라 재현성만 잃는다.
#
#   T1  9개  실습 코드가 직접 import / 실행하는 것
#   T2  3개  `langgraph dev`(Studio 실시간 노드 추적) 3종 세트
#   T3 35개  T1 이 요구하는 전이 의존성
#   T4 32개  T2 가 요구하는 전이 의존성   <- "그래프와 무관해 보이는" 것들이 전부 여기
#
# T4 를 없애는 유일한 방법은 T2(`langgraph dev`)를 포기하는 것이다. 그러면 44개까지
# 줄지만 Studio 화면에서 노드가 하나씩 점등되는 실시간 추적을 볼 수 없게 된다.
# 이 교육과정의 핵심 요구사항이므로 T2/T4 를 유지한다.
# (LangSmith 웹 트레이스 자체는 T1 만으로도 남는다. Studio 실시간 화면만 사라진다.)
# =============================================================================
