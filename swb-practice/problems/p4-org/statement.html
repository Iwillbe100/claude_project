문제 설명

한 회사의 조직도를 관리하는 프로그램을 만들려고 한다. 조직도는 최상위 부서 하나를 루트로 하는 트리이다. 모든 부서에는 ID와 그 부서에 직접 소속된 인원 수가 있다.

어떤 부서의 총 인원은 그 부서와 모든 하위 부서의 인원을 더한 값이다.

부서를 삭제하면 그 부서의 모든 하위 부서도 함께 삭제된다.

구현할 함수

def init(mId: int, mNum: int) -> None

각 테스트 케이스의 처음에 호출된다. ID가 mId이고 인원이 mNum인 최상위 부서 하나만 있는 상태로 만든다.

def add(mId: int, mNum: int, mParent: int) -> int

ID가 mId이고 인원이 mNum인 부서를 mParent 부서 바로 아래에 만든다. 만든 뒤 mParent 부서의 총 인원을 반환한다.
mParent 부서가 존재하지 않으면(삭제된 경우 포함) 부서를 만들지 않고 -1을 반환한다.
mId는 이전에 한 번도 주어진 적 없는 값이다.

def removeDept(mId: int) -> int

mId 부서와 그 모든 하위 부서를 삭제하고, 삭제된 인원의 합을 반환한다.
mId 부서가 존재하지 않으면 -1을 반환한다. 최상위 부서는 주어지지 않는다.

def getTotal(mId: int) -> int

mId 부서의 총 인원을 반환한다. 존재하지 않는 부서이면 -1을 반환한다.

제약 사항

  • 1 ≤ mId ≤ 1,000,000,000
  • 1 ≤ mNum ≤ 100
  • 조직도 트리의 깊이는 항상 100 이하이다.
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 30,000번 호출한다.

예시

호출반환설명
init(10, 5)
add(20, 3, 10)810의 총 인원 = 5 + 3
add(30, 4, 20)720의 총 인원 = 3 + 4
getTotal(10)12
removeDept(20)720과 30이 삭제됨
getTotal(30)-1
add(40, 1, 30)-1
getTotal(10)5
