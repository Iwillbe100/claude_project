문제 설명

창고 바닥은 N × N 격자이다. 각 칸은 빈 칸(0)이거나 벽(1)이다. 이 격자 위에서 로봇들이 움직인다. 한 칸에는 로봇이 최대 한 대만 있을 수 있다.

로봇은 방향을 가지고 있고, 방향 번호는 다음과 같다.

번호방향한 칸 움직이면
0위행 번호가 1 줄어든다
1오른쪽열 번호가 1 늘어난다
2아래행 번호가 1 늘어난다
3왼쪽열 번호가 1 줄어든다

행과 열 번호는 0부터 시작하고, 시계 방향으로 90도 돌면 방향 번호가 1 늘어난다 (3에서 돌면 0이 된다).

구현할 함수

def init(N: int, mMap: list) -> None

각 테스트 케이스의 처음에 호출된다. mMap[r][c]가 1이면 벽이다. 로봇은 한 대도 없는 상태로 시작한다.

def addRobot(mId: int, mR: int, mC: int, mDir: int) -> int

번호가 mId인 로봇을 (mR, mC)에 mDir 방향으로 놓고 1을 반환한다.
다음 중 하나라면 놓지 않고 0을 반환한다.

  • 같은 번호의 로봇이 이미 있다.
  • 그 칸이 벽이다.
  • 그 칸에 다른 로봇이 있다.
def removeRobot(mId: int) -> int

mId 로봇을 치우고 1을 반환한다. 그런 로봇이 없으면 0을 반환한다.

def rotate(mId: int, mK: int) -> int

mId 로봇을 시계 방향으로 mK × 90도 돌린다. mK가 음수이면 반시계 방향이다. 돌린 뒤의 방향 번호를 반환한다.

def move(mId: int, mSteps: int) -> int

mId 로봇이 바라보는 방향으로 한 칸씩 최대 mSteps칸 움직인다. 다음 칸이 다음 중 하나이면 거기서 멈춘다.

  • 격자 밖이다.
  • 벽이다.
  • 다른 로봇이 있다.

실제로 움직인 칸 수를 반환한다 (0일 수도 있다).

def whoAt(mR: int, mC: int) -> int

(mR, mC) 칸에 있는 로봇의 번호를 반환한다. 아무도 없으면 0을 반환한다.

제약 사항

  • 2 ≤ N ≤ 50
  • 1 ≤ mId ≤ 1,000
  • 0 ≤ mDir ≤ 3, -100 ≤ mK ≤ 100, 1 ≤ mSteps ≤ 100
  • rotate와 move는 격자 위에 있는 로봇에 대해서만 호출한다.
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 30,000번 호출한다.

예시

N = 4, 벽은 (0, 2) 한 칸뿐이다.

호출반환설명
addRobot(1, 3, 0, 1)1(3,0), 오른쪽
addRobot(2, 3, 3, 3)1(3,3), 왼쪽
move(1, 5)2(3,2)까지 가고, (3,3)에 로봇 2가 있어서 멈춤
whoAt(3, 2)1
rotate(1, -1)0반시계로 90도 → 위
move(1, 10)2(1,2)까지 가고, (0,2)는 벽이라 멈춤
addRobot(3, 0, 2, 0)0벽
addRobot(1, 0, 0, 0)01번 로봇이 이미 있음
removeRobot(2)1
removeRobot(2)0이미 치움
rotate(1, 5)1(0 + 5) % 4
