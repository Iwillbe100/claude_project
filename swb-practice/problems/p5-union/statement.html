문제 설명

SNS에 사용자가 N명 있고, 사용자에게는 1번부터 N번까지 번호가 붙어 있다. 처음에는 아무도 친구가 아니다.

두 사용자가 친구가 되면, 두 사람의 친구 관계로 이어지는 모든 사람이 하나의 그룹으로 합쳐진다. 즉 A와 B가 친구이고 B와 C가 친구이면 A, B, C는 같은 그룹이다.

구현할 함수

def init(N: int) -> None

각 테스트 케이스의 처음에 호출된다. 사용자는 N명이고, 모두 혼자인 그룹이다.

def merge(mA: int, mB: int) -> int

mA와 mB를 친구로 만든다. 처리한 뒤 mA가 속한 그룹의 인원 수를 반환한다.
이미 같은 그룹이면 아무것도 바뀌지 않고, 그 그룹의 인원 수를 반환한다.

def isSame(mA: int, mB: int) -> int

두 사람이 같은 그룹이면 1, 아니면 0을 반환한다.

def groupSize(mA: int) -> int

mA가 속한 그룹의 인원 수를 반환한다.

def countGroups() -> int

현재 그룹의 개수를 반환한다.

제약 사항

  • 1 ≤ N ≤ 100,000
  • 1 ≤ mA, mB ≤ N
  • 각 테스트 케이스에서 merge, isSame, groupSize, countGroups를 합쳐 최대 100,000번 호출한다.

예시

호출반환설명
init(5)그룹 5개
merge(1, 2)2{1,2}
merge(3, 4)2{3,4}
isSame(1, 3)0
merge(2, 3)4{1,2,3,4}
isSame(1, 4)1
groupSize(5)1
countGroups()2{1,2,3,4}, {5}

힌트: 합칠 때마다 그룹 전체를 훑으면 최악의 경우 시간 초과가 날 수 있다.
