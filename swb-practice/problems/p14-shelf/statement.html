문제 설명

도서관에 책장 칸이 한 줄로 N개 있고, 0번부터 N-1번까지 번호가 붙어 있다. 처음에는 모든 칸이 비어 있다.

사서는 칸에 책을 꽂고, 칸에서 책을 빼고, 여러 칸에 꽂힌 책 수를 세고, "0번 칸부터 차례로 세었을 때 K번째 책이 어느 칸에 있는지"를 찾는다. 한 칸에 꽂힌 책들은 구별하지 않는다.

구현할 함수

def init(N: int) -> None

각 테스트 케이스의 처음에 호출된다. 칸은 N개이고 모두 비어 있다.

def put(mIdx: int, mCnt: int) -> int

mIdx번 칸에 책 mCnt권을 꽂는다. 꽂은 뒤 그 칸의 책 수를 반환한다.

def take(mIdx: int, mCnt: int) -> int

mIdx번 칸에서 책 mCnt권을 뺀다. 칸에 있는 책이 mCnt권보다 적으면 있는 책을 모두 뺀다.
실제로 뺀 책 수를 반환한다.

def count(mL: int, mR: int) -> int

mL번부터 mR번 칸까지(양 끝 포함) 꽂힌 책 수의 합을 반환한다.

def find(mK: int) -> int

0번 칸부터 번호 순서로 책을 세었을 때 mK번째 책이 꽂힌 칸 번호를 반환한다. 즉 0번부터 i번 칸까지의 책 수 합이 mK 이상이 되는 가장 작은 i이다.
전체 책이 mK권보다 적으면 -1을 반환한다.

제약 사항

  • 1 ≤ N ≤ 100,000
  • 0 ≤ mIdx ≤ N-1, 0 ≤ mL ≤ mR ≤ N-1
  • 1 ≤ mCnt ≤ 1,000
  • 1 ≤ mK ≤ 1,000,000,000
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 50,000번 호출한다 (init 제외).

예시

N = 8

호출반환칸별 책 수 (0~7번)
put(0, 2)22 0 0 0 0 0 0 0
put(2, 3)32 0 3 0 0 0 0 0
put(5, 4)42 0 3 0 0 4 0 0
count(1, 5)7
find(3)20번 칸에 1~2번째, 2번 칸에 3~5번째 책
find(6)5
take(2, 5)32 0 0 0 0 4 0 0
find(3)5
find(7)-1전체 6권
put(0, 1)33 0 0 0 0 4 0 0
count(0, 0)3

힌트: 칸 수가 10만이고 호출이 5만 번이라 count를 칸마다 더하면 느리다. 한 칸 수정과 구간 합을 모두 O(log N)에 하는 자료구조를 생각해 보자.
