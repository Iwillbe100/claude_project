문제 설명

공항에 입국 심사대가 있다. 심사대마다 한 사람을 심사하는 데 걸리는 시간이 다르다.

모든 심사대는 동시에 일을 시작하고, 서로 독립적으로 쉬지 않고 일한다. 심사대는 한 번에 한 사람만 심사하고, 심사를 마치면 곧바로 다음 사람을 받는다. 사람은 어느 심사대로 가도 되고, 심사대가 비어 있어도 다른 심사대가 빨리 끝나길 기다릴 수 있다.

줄 선 사람이 M명일 때, 모두가 심사를 마치는 데 걸리는 최소 시간을 구하자.

구현할 함수

def init(N: int, mTime: list) -> None

각 테스트 케이스의 처음에 호출된다. 심사대는 N개이고, mTime[i]는 i번 심사대가 한 사람을 심사하는 데 걸리는 시간이다.

def addDesk(mTime: int) -> None

한 사람을 심사하는 데 mTime이 걸리는 심사대를 하나 늘린다.

def minTime(M: int) -> int

지금 있는 심사대로 M명 모두를 심사하는 데 걸리는 최소 시간을 반환한다. 이 호출은 상태를 바꾸지 않는다.

제약 사항

  • 심사대는 처음 개수와 늘린 개수를 합쳐 항상 1,000개 이하이다.
  • 1 ≤ mTime ≤ 1,000,000,000
  • 1 ≤ M ≤ 1,000,000,000
  • 각 테스트 케이스에서 addDesk와 minTime을 합쳐 최대 300번 호출한다.

예시

호출반환설명
init(2, [7, 10])
minTime(6)2828분이면 7분짜리가 4명, 10분짜리가 2명. 27분이면 3 + 2 = 5명
addDesk(3)
minTime(6)1212분이면 1 + 1 + 4 = 6명

힌트: M이 최대 10억이므로 시간을 1씩 늘려 가며 찾을 수는 없다. 시간 T가 주어졌을 때 심사할 수 있는 사람 수는 T가 커질수록 줄어들지 않는다.
