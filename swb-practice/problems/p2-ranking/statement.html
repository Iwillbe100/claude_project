문제 설명

온라인 게임의 실시간 랭킹 시스템을 만들려고 한다. 사용자의 점수는 계속 바뀌고, 탈퇴하는 사용자도 있다.

언제든지 점수가 가장 높은 사용자 K명을 바로 알 수 있어야 한다.

순위는 점수가 높은 순서로 정하고, 점수가 같으면 ID가 작은 사용자가 앞선다.

구현할 함수

def init() -> None

각 테스트 케이스의 처음에 호출된다. 등록된 사용자가 없는 상태로 만든다.

def update(mId: int, mScore: int) -> None

사용자 mId의 점수를 mScore로 정한다.
등록되지 않은 사용자이면 새로 등록하고, 이미 등록된 사용자이면 점수를 바꾼다.

def removeUser(mId: int) -> int

사용자 mId를 삭제하고, 삭제된 사용자의 점수를 반환한다.
등록되지 않은 사용자이면 -1을 반환한다.

def getTop(K: int, mResult: list) -> int

순위가 높은 사용자의 ID를 차례대로 mResult[0]부터 최대 K개 채운다. mResult는 길이가 K인 리스트이다.
채운 개수를 반환한다. 등록된 사용자가 K명보다 적으면 모든 사용자를 채운다.

제약 사항

  • 1 ≤ mId ≤ 100,000
  • 0 ≤ mScore ≤ 1,000,000
  • 1 ≤ K ≤ 10
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 50,000번 호출한다.

예시
