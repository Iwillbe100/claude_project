문제 설명

택시 호출 서비스를 만든다. 도시는 N × N 격자이고, 좌표 (x, y)는 0 ≤ x, y ≤ N-1인 정수이다. 두 지점 사이의 거리는 맨해튼 거리 |x1 - x2| + |y1 - y2|이다.

손님이 택시를 부르면, 손님 위치에서 거리 L 이내에 있는 대기 중인 택시 중 가장 가까운 택시를 배정한다. 배정된 택시는 운행을 시작하므로 대기 목록에서 빠진다. 운행을 마친 택시는 나중에 다시 대기 목록에 들어올 수 있다.

구현할 함수

def init(N: int, L: int) -> None

각 테스트 케이스의 처음에 호출된다. 도시의 크기는 N × N, 배정 거리 제한은 L이다. 대기 중인 택시는 없다.

def addTaxi(mId: int, mX: int, mY: int) -> None

택시 mId가 (mX, mY)에서 대기를 시작한다. 처음 등장하는 택시이거나, 앞서 callTaxi로 배정되어 운행을 마친 택시이다. 이미 대기 중인 택시로는 호출되지 않는다.

def moveTaxi(mId: int, mX: int, mY: int) -> None

대기 중인 택시 mId가 (mX, mY)로 이동한다. mId는 항상 대기 중인 택시이다.

def callTaxi(mX: int, mY: int) -> int

(mX, mY)에 있는 손님이 택시를 부른다. 대기 중인 택시 중 손님과의 거리가 L 이하인 택시들 가운데

  1. 거리가 가장 가까운 택시,
  2. 거리가 같다면 ID가 가장 작은 택시

를 배정하고 그 ID를 반환한다. 배정된 택시는 대기 목록에서 빠진다. 조건을 만족하는 택시가 없으면 -1을 반환하고 아무것도 바뀌지 않는다.

def countTaxi(mX: int, mY: int) -> int

(mX, mY)에서 거리가 L 이하인 대기 중인 택시의 수를 반환한다.

제약 사항

  • 10 ≤ N ≤ 1,000,000
  • 1 ≤ L ≤ N
  • 1 ≤ mId ≤ 1,000,000,000
  • 대기 중인 택시는 어느 순간에도 최대 20,000대이다.
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 30,000번 호출한다 (init 제외).
  • 한 변이 L인 정사각형 안에 대기 중인 택시가 50대를 넘는 경우는 거의 없다 (택시는 도시 전체에 퍼져 있다).

예시

N = 100, L = 10

호출반환설명
addTaxi(7, 10, 10)
addTaxi(3, 15, 12)
addTaxi(9, 30, 30)
countTaxi(12, 12)27번 거리 4, 3번 거리 3, 9번 거리 36
callTaxi(12, 12)3가장 가까운 3번 배정 (대기 목록에서 빠짐)
addTaxi(5, 14, 10)
callTaxi(12, 10)57번과 5번 모두 거리 2 → ID가 작은 5번
callTaxi(24, 24)-19번은 거리 12, 7번은 거리 28. 모두 L보다 멀다
moveTaxi(9, 26, 28)
callTaxi(24, 24)99번 거리 6
addTaxi(3, 50, 50)운행을 마친 3번이 다시 대기
countTaxi(45, 48)13번 거리 7
callTaxi(10, 20)77번 거리 정확히 10 = L (배정 가능)
countTaxi(10, 20)0

힌트: 매번 모든 택시와 거리를 재면 느리다. 거리 L 이내라면 x, y 좌표 차이가 각각 L 이하라는 점을 이용해 근처의 택시만 확인해 보자.
