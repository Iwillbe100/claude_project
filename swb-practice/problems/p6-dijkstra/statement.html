문제 설명

도시가 N개 있고, 0번부터 N-1번까지 번호가 붙어 있다. 도시 사이에는 양방향 도로가 있고, 도로마다 지나가는 데 걸리는 시간이 정해져 있다. 두 도시 사이에 도로가 여러 개 있을 수도 있다.

도로는 새로 만들 수 있다. 두 도시를 오가는 데 걸리는 최소 시간을 계속 물어본다.

구현할 함수

def init(N: int, K: int, sCity: list, eCity: list, mTime: list) -> None

각 테스트 케이스의 처음에 호출된다. 도시는 N개이고, 처음 도로는 K개이다. i번째 도로는 sCity[i]와 eCity[i]를 잇고, 걸리는 시간은 mTime[i]이다.

def addRoad(mS: int, mE: int, mTime: int) -> None

도시 mS와 mE를 잇는 양방향 도로를 만든다. 걸리는 시간은 mTime이다.

def shortest(mS: int, mE: int) -> int

mS에서 mE까지 가는 데 걸리는 최소 시간을 반환한다. 갈 수 없으면 -1을 반환한다. mS와 mE가 같으면 0이다.

제약 사항

  • 2 ≤ N ≤ 500
  • 0 ≤ K ≤ 2,000
  • 도로의 두 도시는 서로 다르다.
  • 1 ≤ 도로 시간 ≤ 1,000
  • 각 테스트 케이스에서 addRoad와 shortest를 합쳐 최대 1,000번 호출한다.

예시

N = 5, 도로: (0,1,5), (1,2,3), (0,2,10), (2,3,1)

호출반환설명
shortest(0, 3)90→1→2→3 = 5+3+1
shortest(0, 4)-14번 도시는 연결 안 됨
addRoad(0, 3, 4)
shortest(0, 3)4
shortest(1, 3)41→2→3 = 3+1
shortest(2, 2)0
