문제 설명

기차역에서 열차를 편성한다. 열차 맨 앞에는 항상 기관차(번호 0)가 있고, 그 뒤에 객차가 한 줄로 이어진다. 객차마다 서로 다른 번호가 붙어 있다.

객차를 원하는 위치에 붙이고, 떼어 내고, 다른 위치로 옮기는 작업을 처리하는 프로그램을 작성하라. 위치는 항상 "어떤 차량의 바로 뒤"로 정한다.

구현할 함수

def init() -> None

각 테스트 케이스의 처음에 호출된다. 열차에는 기관차만 있다.

def addCar(mId: int, mPrevId: int) -> int

새 객차 mId를 차량 mPrevId의 바로 뒤에 붙인다. 원래 mPrevId 뒤에 있던 객차들은 mId 뒤로 밀린다. mPrevId가 0이면 기관차 바로 뒤이다.
붙인 뒤 열차의 객차 수(기관차 제외)를 반환한다.

def removeCar(mId: int) -> int

객차 mId를 떼어 낸다. 앞뒤 객차는 서로 이어진다.
떼어 내기 전에 mId의 바로 뒤에 있던 객차 번호를 반환한다. 맨 뒤 객차였으면 -1을 반환한다.

def moveCar(mId: int, mPrevId: int) -> int

객차 mId를 떼어서 차량 mPrevId의 바로 뒤에 붙인다.
옮긴 뒤 mId의 바로 뒤에 있는 객차 번호를 반환한다. 맨 뒤이면 -1을 반환한다.

def getCars(mId: int, mCnt: int, mResult: list) -> int

객차 mId부터 뒤쪽으로 차례대로 최대 mCnt대의 번호를 mResult[0]부터 채운다 (mId 자신이 mResult[0]). mResult는 길이가 mCnt인 리스트이다.
채운 개수를 반환한다.

제약 사항

  • 1 ≤ mId ≤ 1,000,000,000. 객차 번호는 테스트 케이스 안에서 다시 쓰이지 않는다 (떼어 낸 번호도 다시 나오지 않는다).
  • addCar의 mId는 새 번호이고, mPrevId는 0이거나 열차에 있는 객차이다.
  • removeCar, getCars의 mId는 열차에 있는 객차이다.
  • moveCar의 mId는 열차에 있는 객차, mPrevId는 0이거나 열차에 있는 객차이고, mId ≠ mPrevId이다.
  • 1 ≤ mCnt ≤ 10
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 100,000번 호출한다.

예시

호출반환열차 (0은 기관차)
addCar(5, 0)10 5
addCar(8, 5)20 5 8
addCar(3, 0)30 3 5 8
addCar(9, 5)40 3 5 9 8
getCars(5, 10, r)3r = [5, 9, 8]
moveCar(3, 8)-10 5 9 8 3
removeCar(9)80 5 8 3
moveCar(8, 0)50 8 5 3
getCars(8, 2, r)2r = [8, 5]

힌트: 파이썬 리스트의 index(), insert(), pop(i)는 모두 O(N)이다. 순서를 리스트로 들고 있지 말고, 객차마다 "앞"과 "뒤"만 기억해 보자.
