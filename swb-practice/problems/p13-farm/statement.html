문제 설명

밭이 한 줄로 N칸 있고, 0번부터 N-1번까지 번호가 붙어 있다. 칸마다 작물이 한 그루씩 자라고 있으며, 처음 높이가 주어진다.

농부는 다음 세 가지 일을 한다.

  • 연속한 구간에 물을 주면 그 구간의 작물이 모두 같은 만큼 자란다.
  • 작물 하나를 수확하면 그 칸의 높이는 0이 된다 (그 자리에서 다시 자란다).
  • 연속한 구간에서 가장 큰 작물의 높이를 확인한다.

구현할 함수

def init(N: int, mHeight: list) -> None

각 테스트 케이스의 처음에 호출된다. mHeight[i]는 i번 칸의 처음 높이이다.

def grow(mL: int, mR: int, mV: int) -> None

mL번부터 mR번까지(양 끝 포함) 모든 칸의 높이에 mV를 더한다.

def cut(mIdx: int) -> int

mIdx번 칸의 현재 높이를 반환하고, 그 칸의 높이를 0으로 만든다.

def tallest(mL: int, mR: int) -> int

mL번부터 mR번까지(양 끝 포함) 칸 중 가장 큰 높이를 반환한다.

제약 사항

  • 1 ≤ N ≤ 100,000
  • 0 ≤ mHeight[i] ≤ 1,000,000
  • 0 ≤ mL ≤ mR ≤ N-1, 0 ≤ mIdx ≤ N-1
  • 1 ≤ mV ≤ 1,000
  • 각 테스트 케이스에서 모든 함수를 합쳐 최대 20,000번 호출한다 (init 제외).

예시

N = 6, 처음 높이 [3, 1, 4, 1, 5, 9]

호출반환높이
tallest(0, 3)4[3, 1, 4, 1, 5, 9]
grow(0, 3, 2)[5, 3, 6, 3, 5, 9]
tallest(0, 4)6
cut(2)6[5, 3, 0, 3, 5, 9]
grow(1, 5, 1)[5, 4, 1, 4, 6, 10]
tallest(1, 3)4
cut(5)10[5, 4, 1, 4, 6, 0]
tallest(3, 5)6

힌트: grow를 칸 하나씩 처리하면 한 번에 최대 10만 번 더해야 한다. 칸을 몇십~몇백 개씩 묶어서 "묶음 전체에 더하기"를 한 번에 처리해 보자.
