문제 설명

단어를 저장하고 지울 수 있는 사전을 만들려고 한다. 같은 단어는 여러 번 저장될 수 있고, 사전은 단어마다 저장된 횟수를 기억한다.

또 어떤 문자열로 시작하는 단어가 사전에 모두 몇 개 있는지 물어볼 수 있다. 이때 같은 단어가 여러 번 저장되어 있으면 그 횟수만큼 센다.

구현할 함수

def init() -> None

각 테스트 케이스의 처음에 호출된다. 사전을 빈 상태로 만든다.

def add(mWord: str) -> int

단어 mWord를 사전에 1개 추가한다. 추가한 뒤 사전에 저장된 mWord의 개수를 반환한다.

def removeWord(mWord: str) -> int

단어 mWord를 사전에서 1개 삭제하고, 삭제한 뒤 남은 mWord의 개수를 반환한다.
사전에 mWord가 없으면 아무것도 하지 않고 -1을 반환한다.

def countPrefix(mPrefix: str) -> int

mPrefix로 시작하는 단어의 총 개수를 반환한다. mPrefix와 똑같은 단어도 포함한다.

제약 사항

  • 단어와 접두사는 영어 소문자로만 이루어지며, 길이는 1 이상 10 이하이다.
  • 각 테스트 케이스에서 add, removeWord, countPrefix를 합쳐 최대 30,000번 호출한다.

예시

호출반환설명
init()
add("abc")1
add("abc")2
add("ab")1
countPrefix("ab")3abc ×2, ab ×1
removeWord("abc")1
removeWord("zz")-1없는 단어
countPrefix("abc")1
