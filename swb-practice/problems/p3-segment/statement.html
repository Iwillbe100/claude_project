문제 설명

공장에 센서 N개가 한 줄로 설치되어 있고, 왼쪽부터 0번에서 N-1번까지 번호가 붙어 있다. 센서마다 측정값이 있으며, 측정값은 수시로 바뀐다.

관리자는 연속한 센서 구간을 골라 그 구간의 편차를 확인하려고 한다. 편차는 구간 안에서 가장 큰 측정값에서 가장 작은 측정값을 뺀 값이다.

구현할 함수

def init(N: int, mValue: list) -> None

각 테스트 케이스의 처음에 호출된다. 센서는 N개이고, mValue[i]는 i번 센서의 처음 측정값이다.

def update(mIdx: int, mValue: int) -> None

mIdx번 센서의 측정값을 mValue로 바꾼다.

def query(mFrom: int, mTo: int) -> int

mFrom번부터 mTo번까지(mFrom과 mTo 포함) 센서들의 측정값 중 최댓값에서 최솟값을 뺀 값을 반환한다.

제약 사항

  • 1 ≤ N ≤ 100,000
  • 0 ≤ 측정값 ≤ 1,000,000,000
  • 0 ≤ mFrom ≤ mTo ≤ N-1
  • 각 테스트 케이스에서 update와 query를 합쳐 최대 50,000번 호출한다.

예시

N = 5, mValue = [3, 8, 1, 6, 4]

호출반환설명
query(0, 4)78 - 1
query(3, 4)26 - 4
update(1, 2)[3, 2, 1, 6, 4]
query(0, 2)23 - 1

힌트: Q번의 질의를 매번 O(N)으로 처리하면 시간 초과가 날 수 있다.
