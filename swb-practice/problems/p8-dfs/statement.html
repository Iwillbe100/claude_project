문제 설명

N × N 크기의 지도가 있다. 각 칸은 바다(0)이거나 땅(1)이다. 땅인 칸이 위, 아래, 왼쪽, 오른쪽으로 이어져 있으면 같은 섬이다. 대각선은 이어진 것으로 보지 않는다.

지도에는 땅을 새로 만들 수 있다. 섬의 넓이와 섬의 개수를 계속 물어본다.

구현할 함수

def init(N: int, mMap: list) -> None

각 테스트 케이스의 처음에 호출된다. mMap[r][c]는 r행 c열 칸의 상태이다. 행과 열 번호는 0부터 시작한다.

def setLand(mR: int, mC: int) -> None

r행 c열 칸을 땅으로 만든다. 이미 땅이면 아무것도 하지 않는다.

def getArea(mR: int, mC: int) -> int

r행 c열 칸이 속한 섬의 넓이(칸 수)를 반환한다. 바다이면 0을 반환한다.

def countIsland() -> int

지도 전체의 섬 개수를 반환한다.

제약 사항

  • 1 ≤ N ≤ 50
  • 0 ≤ mR, mC < N
  • 각 테스트 케이스에서 setLand, getArea, countIsland를 합쳐 최대 500번 호출한다.
  • 땅이 한 줄로 길게 이어져 있으면 섬의 넓이가 1,000을 넘을 수 있다.

예시

1 1 0 0
0 0 0 1
1 0 0 1
0 0 0 0
호출반환설명
countIsland()3왼쪽 위, 오른쪽, 왼쪽 아래 섬
getArea(0, 1)2
getArea(3, 3)0바다
setLand(1, 1)왼쪽 위 섬에 붙는다
setLand(2, 2)오른쪽 섬에 붙는다
setLand(1, 2)두 섬을 이어 준다
getArea(1, 3)73 + 3 + 1
countIsland()2

힌트: 재귀로 DFS를 짜면 깊이가 1,000을 넘을 수 있다. sys.setrecursionlimit으로 한도를 늘리거나, 스택을 직접 써서 반복문으로 짜자.
