문제 설명

N × N 크기의 미로가 있다. 각 칸은 길(0)이거나 벽(1)이다. 길인 칸에서 위, 아래, 왼쪽, 오른쪽의 길인 칸으로 한 칸씩 움직일 수 있다. 벽은 지나갈 수 없다.

벽을 허물거나 길을 막을 수 있다. 두 칸 사이를 가는 최소 이동 횟수를 계속 물어본다.

구현할 함수

def init(N: int, mMap: list) -> None

각 테스트 케이스의 처음에 호출된다. mMap[r][c]는 r행 c열 칸의 상태이다. 행과 열 번호는 0부터 시작한다.

def toggle(mR: int, mC: int) -> None

r행 c열 칸의 상태를 뒤집는다. 길이면 벽으로, 벽이면 길로 바뀐다.

def shortest(mSR: int, mSC: int, mER: int, mEC: int) -> int

(mSR, mSC)에서 (mER, mEC)까지 가는 최소 이동 횟수를 반환한다.
갈 수 없으면 -1을 반환한다. 출발 칸이나 도착 칸이 벽인 경우도 -1이다. 출발 칸과 도착 칸이 같은 길이면 0이다.

제약 사항

  • 2 ≤ N ≤ 40
  • 0 ≤ 모든 행, 열 번호 < N
  • 각 테스트 케이스에서 toggle과 shortest를 합쳐 최대 1,000번 호출한다.

예시

0 0 0 0
1 1 0 1
0 0 0 0
0 1 1 0
호출반환설명
shortest(0, 0, 2, 0)6(1,0)이 벽이라서 오른쪽으로 돌아간다
toggle(1, 0)벽이 길이 된다
shortest(0, 0, 2, 0)2
shortest(0, 0, 3, 0)3
shortest(3, 1, 0, 0)-1출발 칸이 벽
