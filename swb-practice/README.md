# SW B형 연습 (Python)

삼성 SW 역량테스트 B형을 Python으로 연습하는 로컬 채점 사이트입니다.
B형처럼 문제마다 있는 `main.py`가 내가 작성한 `solution.py`의 함수를 호출하고, 테스트 케이스마다 `#번호 점수`를 출력해서 채점합니다.

## 실행

```
node server.js      # 또는 start.bat 더블클릭
```

브라우저에서 http://localhost:3000 을 엽니다. Node.js와 Python만 있으면 되고, 설치할 패키지는 없습니다.

- 다른 Python을 쓰려면 실행 전에 환경변수 `PYTHON`에 경로를 지정합니다.
- 포트를 바꾸려면 환경변수 `PORT`를 지정합니다.
- 서버는 내 컴퓨터(127.0.0.1)에서만 접속할 수 있습니다. 사용자 코드를 그대로 실행하므로 외부에 공개하지 마세요.

## 기능

- **샘플 실행**: `tests/sample.txt`(작은 케이스 3개)로 실행합니다. 결과는 기록에 남지 않습니다.
- **직접 입력**: 입력을 직접 만들어 main.py에 넣고, 그대로 출력된 결과를 봅니다.
- **제출**: 숨은 테스트 케이스 10개(`tests/test.txt`)로 채점하고 기록에 남깁니다. 시간 제한은 테스트 케이스 전체의 실행 시간 합계에 적용됩니다.
- **모범 답안**: 그 문제를 맞힌 뒤에 볼 수 있습니다.
- **시험 모드**: 4시간 카운트다운입니다.
- 작성 중인 코드는 브라우저에 자동으로 저장됩니다.

## 학습 공간

문제가 바로 풀리지 않을 때를 위한 자료입니다.

- **학습 탭**: 강의 12편. 기초(B형 시험 가이드, 파이썬 도구함) → 입문(구현과 시뮬레이션, 해시·트라이, 유니온 파인드, DFS, BFS, 이분 탐색) → 심화(힙, 다익스트라, 세그먼트 트리, 트리). 각 강의에 개념, 그림 풀이, 파이썬 코드(복사 가능), 자주 하는 실수, 연결된 연습 문제가 있고, 읽은 강의는 '학습 완료'로 표시할 수 있습니다.
- **힌트 탭**: 문제마다 3단계 힌트를 한 단계씩 열어 볼 수 있습니다.
- **학습 탭(문제 화면)**: 그 문제에 필요한 강의로 바로 이동합니다.

- **외부 추천 문제**: 강의 하단, 문제 화면의 학습 탭, 학습 목록 맨 아래에 프로그래머스(세그먼트 트리는 백준)의 비슷한 유형 문제 링크가 있습니다. `lessons/practice.json`에서 관리하며, 확인하지 못한 레벨은 적지 않았습니다.

강의는 `lessons/<id>.html`에 쓰고 `lessons/index.json`에 등록합니다. 문제의 힌트는 `problem.json`의 `hints`, 연결 강의는 `lesson`에 적습니다.

| 4 | 조직도 관리 | 트리 / 해시 |

| 7 | 입국 심사 | 이분 탐색 |

## 문제 추가하기

`problems/<문제ID>/` 폴더에 다음 파일을 만듭니다.

| 파일 | 내용 |
|---|---|
| `problem.json` | `title`, `category`, `difficulty`(1~3), `timeLimit`(초), `order` |
| `statement.html` | 문제 설명 |
| `main.py` | 채점용 main. `from solution import ...` 후 `#tc score`를 출력 |
| `template.py` | 처음 에디터에 보여 줄 함수 틀 |
| `solution.py` | 모범 답안 |
| `tests/sample.txt`, `tests/test.txt` | 첫 줄 `T MARK`, 정답이 포함된 입력 |

테스트 데이터는 `tools/gen.py`에 생성 함수를 추가해서 만듭니다(`python tools/gen.py <문제ID>`). 문제를 추가한 뒤에는 서버를 다시 시작하세요.
