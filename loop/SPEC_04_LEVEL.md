# SPEC 04 — 레벨, 속도, 다음 블록, 일시정지

> 근거: 사람이 준 워크숍 순서("SPEC 04 레벨, 속도, 다음 블록, 일시정지 — 기존 기능을 지키는 확장 스펙")와 `slides-export.pdf` 63~64쪽에서 읽을 수 있는 숫자·영문(`floor(…/10)+1`, `max(100, 700-(…-1)×60)`ms, `PLAYING`↔`PAUSED` `P`, `READY LANDED GAME_OVER`, 경계값 0·9·10·19·20, 100ms). 파일 이름은 31쪽 Ralph 명령의 `SPEC_04_LEVEL.md`에 맞췄다. 슬라이드 한글은 판독하지 못해 해석이 필요한 곳은 `[사람 확인 필요]`로 남긴다.

## 1. 목표

- 하는 일: 지운 줄 수로 레벨이 오르고 레벨에 따라 낙하가 빨라지며, 다음에 나올 블록을 미리 보여주고, `P`로 일시정지·재개한다.
- 하지 않는 일: 레벨 점수 배수, 홀드, 7-bag, 고스트 블록, 창을 벗어날 때 자동 일시정지, 효과음은 구현하지 않는다. 기존 SPEC_00~03 동작과 테스트 59개는 그대로 지킨다.

## 2. 기술과 파일 구조

- SPEC_00의 기술 제약을 따른다.
- 새 파일을 추가하지 않는다. 다음 파일만 수정한다.
  - `game.js`: 레벨·낙하 간격·일시정지·종류 지정용 random 순수 함수
  - `main.js`: 레벨별 타이머 간격, 다음 블록 관리·미리보기 그리기, `P` 처리, 일시정지 화면
  - `index.html`: 패널에 `다음 블록` 미리보기와 `레벨` 항목, 보드에 일시정지 안내 마크업 추가(스크립트 순서·`defer`, 기존 문구·`id` 유지)
  - `style.css`: 미리보기·레벨·일시정지 모양(SPEC_02B 토큰)
  - `test.js`: 새 테스트 추가(기존 59개는 삭제·약화·수정하지 않음)
- 게임 상태(`createInitialState`의 필드)와 기존 공개 함수의 동작은 바꾸지 않는다. [사람 확인 필요: 질문 4]

## 3. 화면 정의

### 레벨과 속도 [사람 확인 필요: 질문 1·2·3·9]
- 패널의 `제거한 줄` 아래에 `레벨`이 보인다. 시작 전과 시작 직후 `1`.
- 레벨 = `floor(제거한 줄 / 10) + 1`. 상한 없음.
- 자동 낙하 간격 = `max(100, 700 - (레벨 - 1) × 60)`ms. 레벨 1은 700ms(SPEC_01과 같음), 레벨 11 이상은 100ms.
- 레벨이 오르면 그 고정 다음의 자동 낙하부터 새 간격이 적용된다.
- 점수 규칙은 SPEC_03 그대로다(레벨 배수 없음).

### 다음 블록 [사람 확인 필요: 질문 5]
- 패널 맨 위에 `다음 블록` 칸(4×4)이 있고, 다음에 나올 블록이 생성 방향·종류 색으로 가운데에 보인다.
- 현재 블록이 고정되면 미리보기에 있던 블록이 생성 위치에 나오고, 미리보기는 새 블록으로 바뀐다. 하드 드롭도 같다.
- `READY`와 `GAME_OVER`에서는 미리보기가 비어 있다. `시작`·`재시작` 때 현재 블록과 다음 블록이 함께 정해진다.

### 일시정지 [사람 확인 필요: 질문 6·7·8]
- `P` 키(대소문자, 한글 자판 상태 모두 — 키 위치 `KeyP` 기준)로 `PLAYING` → `PAUSED`, `PAUSED` → `PLAYING`.
- `READY`, `LANDED`, `GAME_OVER`에서 `P`는 아무것도 하지 않는다. 이름 입력칸에 포커스가 있으면 `P`도 입력 글자로 쓰인다(SPEC_03과 같음).
- `PAUSED` 동안:
  - 상태 표시 `PAUSED`, 자동 낙하 멈춤.
  - 방향키·`Space`는 블록을 바꾸지 않는다(브라우저 기본 스크롤은 계속 막는다).
  - 보드가 어두워지고 보드 위에 `일시정지 · P를 누르면 계속`이 보인다.
  - `시작` 버튼은 비활성이다.
- 재개하면 첫 자동 낙하는 재개 시점부터 현재 레벨 간격 뒤다.

### 재시작
- `재시작`하면 레벨 `1`, 간격 700ms, 새 현재·다음 블록으로 시작한다(SPEC_03의 점수·줄 초기화와 함께).

## 4. 상태와 공개 함수

`globalThis.TetrisGame`에 다음을 추가한다. 기존 값·함수·상태 필드는 바꾸지 않는다.

- `LEVEL_LINES`: `10`, `MIN_DROP_INTERVAL_MS`: `100`, `DROP_INTERVAL_STEP_MS`: `60`
- `getLevel(lines)`: `Math.floor(lines / 10) + 1`
- `getDropInterval(level)`: `Math.max(100, DROP_INTERVAL_MS - (level - 1) × 60)`
- `togglePause(state)`: `PLAYING` → `status: PAUSED`인 새 상태, `PAUSED` → `status: PLAYING`인 새 상태. 그 밖에는 입력 상태를 그대로 반환. 입력은 수정하지 않는다.
- `randomForType(type)`: `pickTetrominoType`에 넘기면 항상 `type`이 나오는 random 함수(`() => (TETROMINO_TYPES.indexOf(type) + 0.5) / 7`).
- `PAUSED`에서 `moveLeft`, `moveRight`, `moveDown`, `softDrop`, `rotateClockwise`, `hardDrop`, `lockAndScore`, `lockPiece`, `startGame`, `restartGame`은 입력 상태를 그대로 반환한다(기존 동작이 이미 그렇다는 것을 테스트로 확인).

### main.js 흐름 [사람 확인 필요: 질문 4]
- `main.js`가 다음 종류 `nextType`을 들고 있다. 블록을 새로 놓는 호출(`startGame`, `restartGame`, `lockAndScore`, `hardDrop`)에 `randomForType(nextType)`을 넘기고, 그 직후 `nextType = pickTetrominoType()`으로 새로 뽑는다.
- 자동 낙하 타이머 간격은 `getDropInterval(getLevel(state.lines))`. 간격이 바뀌면 다음 낙하부터 반영한다.
- `P`: 이벤트 `code`가 `KeyP`이고 대상이 이름 입력칸이 아니면 `togglePause`. `PAUSED`가 되면 타이머 정지, `PLAYING`으로 돌아오면 타이머 새로 시작.

## 5. 범위 밖

- 레벨 점수 배수, 홀드, 7-bag, 고스트 블록, 창 포커스 이탈 시 자동 일시정지, 일시정지 메뉴(다시 시작·설정), 효과음, 리더보드에 레벨 기록, 외부 배포
- SPEC 05+ 확장 후보(워크숍 64쪽): 7-bag, 고스트 블록 등

## 8. 수동 검증 시나리오

각 시나리오는 `index.html`을 브라우저에서 직접 열고 새로고침한 상태에서 시작한다.

### A. 다음 블록
1. 시작 전 패널을 본다. → `다음 블록` 칸이 비어 있다.
2. `시작`을 누른다. → `다음 블록` 칸에 블록 하나가 종류 색으로 보인다.
3. `Space`로 현재 블록을 떨어뜨린다. → 방금 미리보기에 있던 블록이 맨 위에 나오고, 미리보기가 새 블록으로 바뀐다.
4. 3을 5번 반복한다. → 매번 같은 규칙이 맞다.

### B. 레벨·속도
1. 시작 직후 패널을 본다. → `레벨` `1`.
2. (가능하면) 10줄을 지운다. → `레벨` `2`가 되고 블록이 눈에 띄게 조금 빨리 떨어진다.
3. 게임 오버 후 `재시작`한다. → `레벨` `1`로 돌아오고 속도도 처음과 같다.

### C. 일시정지
1. `시작` 후 `P`를 누른다. → 상태 `PAUSED`, 보드가 어두워지고 `일시정지 · P를 누르면 계속`이 보이며 블록이 멈춘다.
2. 3초 기다리고 방향키·`Space`를 누른다. → 블록이 그대로다. 페이지도 스크롤되지 않는다.
3. 다시 `P`를 누른다. → 상태 `PLAYING`, 안내가 사라지고 블록이 다시 떨어진다.
4. 한/영 키로 한글 자판으로 바꾼 뒤 `P` 자리 키(ㅔ)를 누른다. → 똑같이 일시정지·재개된다.
5. 시작 전과 게임 오버 상태에서 `P`를 누른다. → 아무 변화가 없다.

### D. 기존 기능 회귀
1. 줄을 지운다. → 금빛 띠·별가루 연출, 점수 +100, `제거한 줄` +1.
2. 게임 오버 후 이름 `별님p`를 입력해 저장한다. → `p`가 입력되고(일시정지 안 됨) 기록이 저장·강조된다.

### E. 390px·콘솔
1. 390px 폭에서 미리보기·레벨·일시정지 안내를 본다. → 가로 스크롤이 없고 글자가 잘리지 않는다.
2. 콘솔을 본다. → 오류가 없다.
