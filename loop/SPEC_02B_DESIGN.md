# SPEC 02B — 동화풍 디자인과 고정·줄 제거 연출

> 워크숍 순서(03 점수·하드 드롭·리더보드, 04 레벨·속도·미리보기·일시정지)의 번호를 지키기 위해 02B로 둔다. (결정 9)

## 1. 목표

- 하는 일: 화면을 "성 위 밤하늘의 불꽃놀이" 같은 디즈니풍 동화 분위기로 바꾸고, 블록 고정 순간과 줄 제거 순간에 연출을 넣는다. 줄을 여러 개 동시에 지울수록 연출이 커진다.
- 하지 않는 일: 게임 규칙·속도·타이밍·상태 값은 바꾸지 않는다. 점수, 하드 드롭, 리더보드, 레벨, 미리보기, 일시정지는 구현하지 않는다.

## 2. 기술과 파일 구조

- SPEC_00의 기술 제약을 그대로 따른다. 외부 글꼴(Google Fonts 등), 외부 이미지, `@import`, 외부 URL을 쓰지 않는다. 글꼴은 기기에 설치된 시스템 글꼴만 쓴다. (결정 2)
- 다음 파일만 수정한다.
  - `style.css`: 색·글꼴·배경·보드 틀·블록 질감·버튼·연출 애니메이션
  - `main.js`: 효과 레이어 생성, 고정·줄 제거 순간 감지, 효과 요소 추가·제거
- 바꾸지 않는 파일: `game.js`, `index.html`, `test.html`, `test.js`. 화면 문구(제목 `TETRIS LOOP`, `점수`, `제거한 줄`, `게임 상태`, 상태 값, `시작`/`재시작`, 조작 안내 문구)는 그대로다.
- 효과 요소는 보드 위에 겹친 별도 레이어(`main.js`가 만든 요소, `pointer-events: none`)에만 넣는다. 보드 셀의 `className`은 지금처럼 `render()`만 바꾼다.
- 효과가 끝나면 효과 요소를 DOM에서 지운다.

## 3. 화면 정의

### 디자인 방향 (결정 1)
- "디즈니 느낌"을 **동화 속 밤하늘과 성 불꽃놀이**로 해석한다: 깊은 남보라 밤하늘, 흩뿌린 별, 금빛 장식, 동화책 같은 제목 글씨, 보석처럼 빛나는 블록, 줄을 지우면 불꽃이 터진다.
- 디즈니 상표 요소(로고, 캐릭터, 성 실루엣, 디즈니 로고 모양 글꼴, "Disney" 문구)는 쓰지 않는다.
- 대담함은 **줄 제거 불꽃** 한 곳에 쓰고, 나머지 화면은 차분하게 둔다. 저절로 반복되는 애니메이션(별이 계속 반짝임 등)은 넣지 않는다.

### 색 (디자인 토큰)
| 이름 | 값 | 쓰임 |
|---|---|---|
| Midnight | `#1B1F4B` | 페이지 배경 바탕 |
| Twilight | `#3A2F7A` | 배경 위쪽 노을빛, 패널 바탕 |
| Well | `#141838` | 보드 안쪽(빈 칸 바탕) |
| Stardust Gold | `#F6D47A` | 제목, 보드 금테, 버튼, 고정 반짝임 |
| Moonlight | `#F3EEFF` | 본문·숫자 |
| Mist | `#B9B3E0` | 패널 이름표, 조작 안내 |

- 배경: Midnight→Twilight 세로 그라데이션 위에 CSS로 그린 작은 별 점들(정지 상태).
- 블록 7색은 SPEC_01 색 이름을 유지하고 보석 질감(안쪽 하이라이트·아래쪽 그림자)만 더한다. (결정 6)
  - I 하늘색 `#5EE3F5`, O 노랑 `#FFD45C`, T 보라 `#B07CFF`, S 초록 `#5FDB8A`, Z 빨강 `#FF6B81`, J 파랑 `#5B8CFF`, L 주황 `#FFA552`

### 글꼴
- 제목: `Gabriola`(Windows 기본, 장식 서체) → `Snell Roundhand`, `Apple Chancery`(macOS) → `Palatino Linotype` → serif. 금빛 그라데이션 글자와 은은한 빛.
- 그 밖의 글자: `Palatino Linotype`, `Book Antiqua`, `Palatino`, 한글은 `바탕`(Batang), `AppleMyungjo` → serif. 숫자는 자릿수 너비 고정(`tabular-nums`).
- 대문자 이름표, 한 단어만 강조, 위에 붙이는 작은 머리말은 쓰지 않는다.

### 배치
```
            TETRIS LOOP            ← 금빛 동화책 제목(가운데)
   ╔══════════════╗  ┌─────────┐
   ║  보드 10×20  ║  │ 점수     │  ← 패널: 금색 얇은 테두리, 둥근 모서리
   ║  (금테 이중선) ║  │ 제거한 줄 │
   ║  + 효과 레이어 ║  │ 게임 상태 │
   ╚══════════════╝  └─────────┘
       [ 시작 ]                     ← 금빛 알약 버튼
   ← → ↓ 이동 · ↑ 회전 · Space 하드 드롭 · P 일시정지
```
- 배치 구조는 SPEC_00과 같다(데스크톱 보드 왼쪽·패널 오른쪽, 640px 이하 세로 배치, 390px 가로 스크롤 없음).
- 보드 틀: 금색 바깥선 + 남색 틈 + 금색 안쪽선의 이중 테(마법 거울 액자), 은은한 금빛 바깥 빛.
- 버튼: 금빛 바탕, 남색 글자, 비활성은 흐린 보라. 키보드 포커스는 금색 외곽선으로 보인다.

### 연출
- 페이지 처음 열 때: 제목에 금빛 광택이 한 번 지나간다(약 1.2초, 1회).
- 고정 순간(`LANDED` → 고정될 때) (결정 5)
  - 고정된 4칸 자리에 금빛 반짝임이 한 번 커졌다 사라진다(약 0.35초).
- 줄 제거 순간 (결정 3·4)
  - 게임 상태는 즉시 바뀌고(줄이 바로 지워지고 위 칸이 내려옴), 연출은 그 위 효과 레이어에 겹쳐 보인다. 게임 진행·타이머는 멈추지 않는다.
  - 1줄: 지운 줄 자리에 가운데에서 양옆으로 퍼지는 금빛 띠 + 별가루 불꽃(줄당 12개 이상) 사방으로 튀었다가 떨어지며 사라짐(약 0.9초).
  - 2~3줄: 위 연출 + 보드 안에서 둥근 불꽃 1개(2줄) / 2개(3줄)가 터짐.
  - 4줄: 위 연출 + 불꽃 3개 + 보드가 짧게 흔들림(약 0.3초).
  - 불꽃 색은 금색과 지운 줄에 있던 블록 색을 섞는다.
  - 모든 효과는 보드 영역 안에서만 보이고(보드 밖으로 넘치지 않음), 끝나면 DOM에서 지워진다.
- 움직임 줄이기: 기기 설정에서 "애니메이션 줄이기"(`prefers-reduced-motion: reduce`)가 켜져 있으면 제목 광택·흔들림·불꽃 입자는 나오지 않고, 고정·줄 제거 자리의 짧은 밝아짐(0.2초 이내)만 보인다. (결정 8)

## 4. 상태와 공개 함수

- `globalThis.TetrisGame`과 `game.js`는 바꾸지 않는다.
- `main.js`는 고정 직전(`drop()`에서 `LANDED`일 때) 공개 함수 `getPieceCells`와 현재 `board`로 고정될 칸과 가득 찰 줄 번호를 계산하고, `lockPiece` 결과를 반영한 뒤 그 정보로 효과를 만든다.
- 효과는 상태(`state`)를 읽기만 하고 바꾸지 않는다.

## 7. 자동 검증

- 게임 로직이 바뀌지 않으므로 `test.js`에 테스트를 추가하지 않는다. 기존 46개 통과로 기능 불변을 확인한다.
- 정적 점검: 백업 대비 diff, 문구 grep, 금지 패턴 grep, `prefers-reduced-motion`·`:focus-visible` grep.
- 브라우저 자동화(에이전트): 블록 순서를 테스트 브라우저 안에서만 고정해 1줄·4줄 제거를 만들고, 효과 레이어 자식 수와 390px `scrollWidth`를 확인한다. 스크린샷을 찍어 에이전트가 1차로 본다(판정은 사람).

## 8. 수동 검증 시나리오

각 시나리오는 `index.html`을 브라우저에서 직접 열고 새로고침한 상태에서 시작한다.

### A. 분위기·색·글꼴
1. 페이지를 연다. → 남보라 밤하늘 배경에 작은 별들이 보이고, 제목 `TETRIS LOOP`가 금빛 장식 서체로 보이며, 처음에 한 번 금빛 광택이 지나간다.
2. 보드를 본다. → 금색 이중 테두리 액자 안에 10×20 칸이 보인다.
3. `시작`을 누르고 여러 블록을 본다. → 블록이 보석처럼 윤이 나고, 7종 색이 SPEC_01 색 이름(I 하늘색, O 노랑, T 보라, S 초록, Z 빨강, J 파랑, L 주황)과 맞으며 서로 구별된다.
4. 전체를 본다. → 사람이 보기에 "디즈니풍 동화 분위기"로 느껴진다. 디즈니 로고·캐릭터는 없다.

### B. 고정 연출
1. 블록이 바닥에 고정되는 순간을 본다. → 그 4칸 자리에 금빛 반짝임이 한 번 커졌다 사라진다.
2. 여러 번 반복한다. → 고정될 때마다 같은 연출이 나온다.

### C. 줄 제거 연출
1. 맨 아래 줄을 채워 1줄을 지운다. → 그 줄 자리에 금빛 띠가 양옆으로 퍼지고 별가루가 튀었다 떨어지며 1초 안에 사라진다. `제거한 줄`이 1 늘어난다.
2. 가능하면 2줄 이상을 한 번에 지운다. → 1줄 때보다 연출이 크다(둥근 불꽃이 터짐).
3. (가능하면) 4줄을 한 번에 지운다. → 불꽃 여러 개와 보드 흔들림이 보인다.
4. 연출이 보드 밖으로 넘치지 않는다.

### D. 게임 진행 불변
1. `시작` 후 손대지 않는다. → 블록이 한 칸씩 떨어지고, 10초 시점에 첫 블록이 아직 바닥에 닿지 않는다.
2. 줄을 지운 직후에도 다음 블록이 바로 나타나 같은 속도로 떨어진다(연출 때문에 멈추지 않는다).
3. 방향키 이동·회전, 게임 오버, `재시작`이 SPEC_02와 같게 동작한다.

### E. 390px·움직임 줄이기·콘솔
1. 화면 폭을 390px로 줄이고 줄을 지운다. → 가로 스크롤이 생기지 않는다.
2. 운영체제의 "애니메이션 줄이기"를 켜고 새로고침한다(Windows: 설정 → 접근성 → 시각 효과 → 애니메이션 효과 끄기). → 제목 광택·불꽃·흔들림 없이 짧은 밝아짐만 보인다.
3. `Tab`으로 버튼에 포커스를 옮긴다. → 금색 포커스 테두리가 보인다.
4. 콘솔을 본다. → 오류가 없다.

## 9. 안전과 정지 조건

- 프로젝트 폴더 밖 파일을 만들거나 수정하지 않는다.
- 외부 배포, 유료 서비스, 외부 글꼴·이미지를 사용하지 않는다.
- 같은 실패가 두 번 반복되거나 총 세 번 실행해도 완료하지 못하면 중단한다.
- 이 문서에 없는 화면·기술 결정을 해야 하면 추측하지 않고 `[사람 확인 필요]`로 보고한다.
- `game.js`나 테스트를 바꿔야만 연출이 가능한 상황이면 중단하고 보고한다.

## 디자인 계획 검토 기록

초안을 만들며 일반적인 기본값으로 흐른 부분을 고쳤다.
- 처음 떠올린 "검정 배경 + 형광 강조 1색"(흔한 게임 화면 기본값) → 동화 밤하늘의 남보라 + 금빛으로 바꿨다. 소재(밤하늘 불꽃놀이)에서 나온 색이다.
- 패널·보드에 같은 둥근 모서리와 회색 그림자를 쓰는 카드 묶음 → 보드는 금테 이중선 액자, 패널은 얇은 금 테두리로 위계를 나눴다.
- 별이 계속 반짝이는 배경 → 상시 움직임은 빼고, 사람의 행동(고정·줄 제거)에 반응하는 연출에만 움직임을 썼다.
